CPU Sederhana Menghitung Netto

Jalankan program kecil "netto = bruto − tara" di CPU akumulator sederhana. Ikuti fase fetch, decode, dan execute, lihat isi register berubah, dan hitung berapa kali bus dipakai. Setelah itu, hitung ruang alamat dan lebar pita bus.

1Jalankan program2Ruang alamat dan lebar pita3Kuis

Fetch → decode → execute

Set instruksi

1xx LOAD xx : AC ← M[xx] 2xx ADD xx : AC ← AC + M[xx] 3xx SUB xx : AC ← AC − M[xx] 4xx STORE xx : M[xx] ← AC 5xx MULP xx : AC ← AC × M[xx] ÷ 100 000 HALT

Alamat 00–09 berisi program, 10 ke atas berisi data (kg). Baris kuning = alamat yang sedang diakses lewat bus.

Bus alamat dan bus data

Rumus

ruang alamat = 2ⁿ byte lebar pita = (lebar ÷ 8) × transfer/s

DDR4-3200 = 3.200 juta transfer per detik pada bus 64 bit. Batang membandingkan dengan SSD SATA (0,55 GB/s) dan SSD NVMe PCIe 4.0 (±7 GB/s).
