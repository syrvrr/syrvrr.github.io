Model waktu
N+1 : (1 + N) × latensi
JOIN: 1 × latensi + waktu baca baris
Latensi 1 ms wajar bila database satu server dengan PHP. Di cloud dengan database terpisah (P13), 5–20 ms per query umum. Geser latensi dan lihat N+1 memburuk.

B-tree
tanpa indeks : baca n baris (full scan)
dengan indeks: ±log_f(n) halaman + baris hasil
f (fan-out) ≈ 500 kunci per halaman
40 pemasok, jadi satu pemasok punya ±n/40 tiket. Indeks mempercepat baca, tetapi setiap INSERT juga harus memperbarui indeks.
