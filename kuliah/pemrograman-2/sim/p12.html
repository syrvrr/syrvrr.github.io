Git Tim dan Alur Surat Pengantar

Jalankan perintah Git satu per satu dan lihat grafik commit dan cabang tumbuh, termasuk konflik saat dua orang mengubah baris yang sama. Lalu uji mesin status surat pengantar TBS dari kebun sampai tiket cetak.

Alur cabang fitur

git switch -c fitur-sp ... commit ... git switch main git merge fitur-sp

Coba urutan: commit di fitur, commit di main pada baris yang sama, lalu merge: terjadi konflik. Selesaikan, lalu commit hasil merge.

Surat pengantar SP-0412

Transisi sah

draf → dikirim → tiba → ditimbang → selesai draf/dikirim → batal tiba → ditolak (sortasi)

Aturan ini ditulis di satu tempat (kelas SuratPengantar). Transisi yang tidak sah melempar exception, bukan diam-diam diterima.
