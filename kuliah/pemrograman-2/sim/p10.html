Penjelajah REST API SiTBS

Kirim permintaan GET, POST, PUT, dan DELETE ke API tiket tiruan dan amati kode status serta JSON yang kembali. Lalu cocokkan situasi dengan kode status HTTP yang tepat dan periksa apakah teks JSON Anda sah.

/api/tiket

Rute

GET /api/tiket daftar GET /api/tiket/{id} satu tiket POST /api/tiket buat → 201 PUT /api/tiket/{id} ganti → 200 DELETE /api/tiket/{id} hapus → 204

Data di halaman ini tiruan dan tersimpan sementara. API sungguhan di P10 ditulis dengan PHP: header('Content-Type: application/json'), http_response_code(), json_encode().
