Definisi Big O

      
T(n) = O(g(n)) ⇔ ada c > 0 dan n₀
sehingga T(n) ≤ c·g(n) untuk n ≥ n₀

      
Contoh: 3n² + 5n + 2 ≤ 4n² untuk n ≥ 6. Jadi 3n² + 5n + 2 = O(n²). Konstanta dan suku kecil tidak menentukan laju.

def ganda_set(t):           # O(n)
    sudah = set()
    for x in t:
        if x in sudah: ...
        sudah.add(x)
