Bagi, Partisi, dan Heap

Merge sort, quick sort, dan heap sort menurunkan biaya mengurutkan dari n² menjadi n log n. Jalankan masing-masing langkah demi langkah, lalu bandingkan jumlah perbandingannya dengan batas bawah log₂(n!) yang tidak bisa dikalahkan.

Bagi dua, urutkan, gabungkan

Bukti n log₂ n

T(n) = 2T(n/2) + n = 4T(n/4) + 2n = 2ᵏ T(n/2ᵏ) + k·n k = log₂ n → T(n) = n log₂ n

Gambar di kiri adalah bukti itu: setiap baris (tingkat) menggabungkan total n elemen, dan ada log₂ n tingkat. n = 8 → 3 tingkat × 8 = 24 sebagai batas atas.

Menggabung

while i < len(L) and j < len(R):
    if L[i] <= R[j]: hasil.append(L[i]); i += 1
    else:            hasil.append(R[j]); j += 1
hasil += L[i:] + R[j:]

Partisi di sekitar pivot

Rumus

partisi n elemen: n − 1 perbandingan baik : T(n) = 2T(n/2) + n = O(n log n) buruk: T(n) = T(n−1) + n = n(n+1)/2 = O(n²)

Pilih data "sudah terurut": pivot selalu terbesar, sehingga setiap partisi hanya mengurangi satu elemen.

Partisi Lomuto

pivot, i = a[hi], lo - 1
for j in range(lo, hi):
    if a[j] <= pivot:
        i += 1; a[i], a[j] = a[j], a[i]
a[i + 1], a[hi] = a[hi], a[i + 1]

Ambil yang terbesar, taruh di ujung

Rumus

bangun heap: Σ (n/2ʰ⁺¹)·h = n·Σ h/2ʰ⁺¹ = n → O(n) n kali turun ≤ log₂ n → O(n log n) memori tambahan: O(1)

Max-heap: induk ≥ anak. Rumus indeks sama dengan pertemuan 9: induk(i) = ⌊(i−1)/2⌋, anak 2i+1 dan 2i+2.

Mengapa ada batas bawah?

Pengurutan dengan perbandingan bisa digambar sebagai pohon keputusan ya/tidak. Pohon itu harus punya n! daun (satu untuk setiap urutan yang mungkin). Pohon biner dengan n! daun tingginya minimal log₂(n!).

log₂(n!) ≈ n log₂ n − 1,44 n (Stirling)

Skor

Ringkasan

  • Merge: n log₂ n, stabil, memori O(n).
  • Quick: rata-rata n log n, terburuk n².
  • Heap: n log n, memori O(1), tidak stabil.
  • Batas bawah log₂(n!).
