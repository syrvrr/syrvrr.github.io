Pohon Kebun dan Indeks Pemasok

Pohon menyimpan hierarki (perusahaan, kebun, afdeling, blok) dan indeks pencarian (binary search tree). Tambahkan dan hapus kunci di BST, jalankan empat cara penelusuran, lalu hitung total produksi kebun secara rekursif.

1Binary search tree2Total produksi kebun3Kuis

Kiri lebih kecil, kanan lebih besar

Rumus pohon biner

simpul di tingkat k ≤ 2ᵏ simpul pohon setinggi h ≤ 2ʰ⁺¹ − 1 tinggi minimum = ⌈log₂(n + 1)⌉ − 1 cari, sisip, hapus = O(h)

Bukti: 1 + 2 + 4 + … + 2ʰ = 2ʰ⁺¹ − 1 (deret geometri). Klik "Isi 8 kunci terurut" untuk melihat h = n − 1: pohon menjadi rantai.

Hapus: tiga kasus

  • Daun: lepas saja.
  • Satu anak: anak menggantikan posisinya.
  • Dua anak: ganti dengan penerus inorder (terkecil di subpohon kanan), lalu hapus penerus itu.

Satu fungsi rekursif untuk semua tingkat

PT Bumi Sawit Lestari: perusahaan → kebun → afdeling → blok. Nilai blok = ton TBS Oktober 2026 (data SiTBS). Klik nama untuk membuka cabang.

Rumus rekursif

total(s) = nilai(s) bila s daun total(s) = Σ total(a), a anak s selain itu tinggi(s) = 0 bila daun; 1 + max tinggi(a)

Setiap simpul dikunjungi sekali: O(n). Anak dihitung dulu, baru induknya (postorder).

Kode

def total(s):
    if not s.anak:
        return s.nilai
    return sum(total(a) for a in s.anak)

Ringkasan

  • BST: kiri < akar < kanan.
  • Inorder BST = terurut.
  • O(h); h_min = ⌈log₂(n+1)⌉ − 1.
  • total rekursif O(n).
