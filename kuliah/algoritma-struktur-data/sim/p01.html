Tiket Timbang sebagai ADT

Satu tiket timbang TBS punya data (bruto, tara, potongan) dan aturan yang tidak boleh dilanggar. Di sini Anda mencoba mengisi tiket, melihat aturan menolak data salah, dan memeriksa batas tipe data yang menyimpannya.

Kode ADT


    
Rumus tiket

      
netto    = bruto − tara
diterima = round(netto × (1 − potongan/100))
nilai    = diterima × harga

      
ADT = data + aturan + operasi. Aturan diperiksa sekali saat tiket dibuat, sehingga fungsi lain tidak perlu memeriksa ulang.

Rumus

      
banyak pola   N = 2ⁿ
bilangan bertanda: −2ⁿ⁻¹ ≤ x ≤ 2ⁿ⁻¹ − 1

      
Separuh pola dipakai untuk bilangan negatif. Bit paling kiri bernilai −2ⁿ⁻¹, bit lain bernilai positif.
