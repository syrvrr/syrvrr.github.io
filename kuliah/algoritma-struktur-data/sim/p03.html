Larik Produksi Blok

Larik dua dimensi menyimpan tabel, misalnya produksi blok kebun per minggu. Di memori, tabel itu sebenarnya satu baris panjang. Klik sel untuk melihat alamatnya dihitung, geser kolom untuk melihat biaya sisip, dan coba indeks di luar batas.

Klik satu sel, lihat alamatnya dihitung

Memori row-major (baris demi baris)

Memori column-major (kolom demi kolom)

Rumus alamat

row-major : basis + (i × kolom + j) × ukuran column-major: basis + (j × baris + i) × ukuran

Bukti: sel [i][j] didahului i baris penuh (i × kolom sel) ditambah j sel di barisnya. Itu sebabnya offsetnya i × kolom + j.

Satu perkalian dan satu penjumlahan, berapa pun ukuran larik: akses O(1).

Contoh BSL

Baris = blok kebun, kolom = minggu. Nilai sel = ton TBS. Python dan C memakai row-major; Fortran dan MATLAB column-major.

Menyisipkan minggu baru: siapa yang harus pindah?

Rumus biaya

pemindahan = baris × (kolom − j) rata-rata (j acak) ≈ baris × kolom / 2 → O(baris × kolom)

Elemen larik berdampingan di memori, jadi setiap elemen di kanan posisi j harus bergeser satu tempat.

Kode

def sisip_kolom(self, j, nilai=0):
    for i in range(self.baris):
        self.data[i].insert(j, nilai)
    self.kolom += 1

Membaca kolom yang tidak ada

Juli 2024: sebuah program keamanan membaca kolom ke-21 dari data yang hanya punya 20 kolom. 8,5 juta komputer berhenti. Coba sendiri di larik 20 kolom ini.

Syarat indeks sah

0 ≤ i < baris dan 0 ≤ j < kolom

Larik 20 kolom punya indeks 0 sampai 19. Indeks 20 sudah di luar.

Pemeriksaan di Larik2D

def ambil(self, i, j):
    if not (0 <= i < self.baris and 0 <= j < self.kolom):
        raise IndexError(f"[{i}][{j}] di luar batas")
    return self.data[i][j]

Ringkasan

  • N = baris × kolom.
  • Row-major: basis + (i·kolom + j)·ukuran.
  • Akses O(1); sisip kolom O(baris × kolom).
  • Indeks sah: 0 ≤ j < kolom.
