Tumpukan, Kurung, dan Undo

Tumpukan bekerja seperti tumpukan keranjang TBS: yang terakhir ditaruh, pertama diambil. Pola ini memeriksa kurung pada rumus, menyimpan riwayat undo, dan mengatur pemanggilan fungsi rekursif.

push  : a[n] = x ; n = n + 1
pop   : n = n − 1 ; kembalikan a[n]
puncak: a[n − 1]
semua O(1)

  





  

    
Apakah kurungnya seimbang?

    
    

    

    
Tumpukan
Tinggi h(t)
h(t) = (#buka − #tutup) sampai karakter t

    

    

  

  

    
Syarat seimbang
1. h(t) ≥ 0 untuk setiap t
2. h(akhir) = 0
3. setiap tutup cocok dengan puncak
Syarat 1-2 saja belum cukup: "(]" punya h yang benar, tetapi jenisnya tidak cocok. Biaya: n karakter × O(1) = O(n).

    
Kode
def seimbang(s):
    pas = {')': '(', ']': '[', '}': '{'}
    t = Tumpukan()
    for c in s:
        if c in '([{': t.push(c)
        elif c in pas:
            if t.kosong() or t.pop() != pas[c]:
                return False
    return t.kosong()

Tumpukan redo

    

    

  

  

    
Aturan
ubah(x): undo.push(nilai); nilai = x; redo.kosongkan()
undo   : redo.push(nilai); nilai = undo.pop()
redo   : undo.push(nilai); nilai = redo.pop()
|undo| + |redo| ≤ jumlah aksi ; tiap operasi O(1)
Aksi baru mengosongkan redo. Inilah jebakan yang sering keliru di soal UTS.

  





  

    
Fungsi rekursif memakai tumpukan

    
    
Call stack

    

    

  

  

    
Kode
def jumlah(a):
    if not a:            # kasus dasar
        return 0
    return a[0] + jumlah(a[1:])

    
Rumus
kedalaman = n + 1 bingkai
salinan a[1:] = (n−1) + … + 1 = n(n−1)/2 → O(n²)
Tanpa kasus dasar, bingkai terus bertambah sampai RecursionError (batas Python 1.000).
