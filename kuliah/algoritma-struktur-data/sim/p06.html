Rantai Dua Arah dan Rotasi Panen

Senarai ganda menyimpan dua penunjuk per simpul, jadi simpul bisa dilepas tanpa mencari pendahulunya. Senarai melingkar tidak punya ujung, cocok untuk jadwal yang berulang seperti rotasi panen blok kebun.

Rumus biaya

      
ganda : lepas(X) = 2 penugasan → O(1)
tunggal: cari pendahulu ≈ (n + 1)/2 langkah → O(n)
memori tambahan ganda: n rujukan sebelum

      
Panah hijau di atas = berikut, panah biru di bawah = sebelum.

Rumus rotasi

      
blok(d) = urutan[(awal + d) mod n]

      
Bukti berulang: (awal + d + n) mod n = (awal + d) mod n. Menambah n tidak mengubah sisa bagi n, jadi jadwal berulang setiap n hari.

      
tambah setelah ekor:
baru.berikut = ekor.berikut   # kepala
ekor.berikut = baru
ekor = baru        → O(1)

    

    
Konteks kebun
Rotasi panen 6/7: setiap blok dipanen sekali dalam 7 hari. Senarai melingkar tidak punya None di ujung; setelah blok terakhir, giliran kembali ke blok pertama.
