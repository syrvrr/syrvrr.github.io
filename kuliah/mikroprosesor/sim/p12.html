Pantulan Tombol, Debounce, dan Resistor Pull-up

Tombol mekanis tidak berpindah bersih dari HIGH ke LOW: kontaknya memantul beberapa milidetik. Atur lama pantulan dan jendela debounce, lalu lihat berapa kali penghitung janjang bertambah dari satu kali tekan. Di tab kedua, bandingkan pin tanpa resistor, INPUT_PULLUP, dan pull-down eksternal.

Debounce berbasis millis()

if (baca != terakhir) tUbah = millis(); if (millis() - tUbah > JENDELA && baca != stabil) { stabil = baca; if (stabil == LOW) hitung++; } terakhir = baca;

Ganssle mengukur pantulan rata-rata ±1,5 ms, dengan sebagian tombol sampai lebih dari 6 ms. Jendela 10–20 ms aman untuk tombol panel.

Konfigurasi pin masukan

Ringkas

  • INPUT_PULLUP: resistor internal 20–50 kΩ ke 5 V
  • Tombol dipasang antara pin dan GND, sehingga ditekan = LOW
  • Tanpa resistor, pin "mengambang" dan menangkap derau
  • Arus pull-up hanya ±0,1–0,25 mA saat ditekan
