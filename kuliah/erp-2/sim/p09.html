REST API ERPNext dan Bagian Agen AI

Aplikasi lain dan agen AI berbicara dengan ERPNext lewat REST API. Susun permintaan GET dengan filter dan field, lihat URL dan jawaban JSON yang dikembalikan, lalu kenali bagian-bagian sebuah agen AI.

1Penyusun permintaan2Bagian agen AI3Kuis

GET /api/resource/Supplier

Field yang diminta

    

  

  

    
Bentuk permintaan
GET /api/resource/{DocType}
  ?fields=["name","supplier_group"]
  &filters=[["supplier_group","=","Agen TBS"]]
  &limit_page_length=20
Header: Authorization: token api_key:api_secret
Di n8n, node HTTP Request atau node ERPNext mengirim permintaan ini. Kunci API dibuat per pengguna; beri role dengan izin minimum.

  





  

    
Komponen ini bagian agen yang mana?

    

    

    

  

  

    
Anatomi agen
pemicu     : pesan, jadwal, webhook
model      : LLM yang menalar
instruksi  : peran, batas, gaya jawab
alat       : API yang boleh dipanggil
memori     : riwayat percakapan
pengaman   : persetujuan manusia, log

  





  
Uji pemahaman
Pilih satu jawaban. Penjelasan muncul langsung.

Ringkasan
  • /api/resource/DocType untuk membaca daftar.
  • fields, filters, limit_page_length.
  • Agen = model + instruksi + alat + pengaman.
