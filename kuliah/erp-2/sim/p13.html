Jalur Kritis dan Earned Value

Proyek agen AI PT BSL dikejar tenggat EUDR. Ubah durasi tugas dan lihat jalur kritis bergeser, lalu ukur kesehatan proyek di minggu ke-4 dengan indeks jadwal dan indeks biaya.

Tujuh tugas, durasi dalam hari kerja

Rumus metode jalur kritis

maju : ES = max(EF pendahulu), EF = ES + d mundur: LF = min(LS penerus), LS = LF − d float = LS − ES kritis ⇔ float = 0 durasi proyek = max(EF)

Batang merah = kritis. Garis abu-abu di belakang batang biru = float, waktu longgar yang boleh dipakai tanpa menggeser akhir proyek.

Minggu ke-4 proyek

Rumus earned value

EV = % selesai × BAC SPI = EV / PV (< 1 terlambat) CPI = EV / AC (< 1 boros) SV = EV − PV CV = EV − AC EAC = BAC / CPI (perkiraan biaya akhir)

Uji pemahaman

Pilih satu jawaban. Penjelasan muncul langsung.

Skor

Ringkasan

  • Jalur kritis: float = 0.
  • SPI = EV / PV, CPI = EV / AC.
  • EAC = BAC / CPI.
