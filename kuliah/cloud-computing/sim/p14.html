Kalkulator SLA Angka Sembilan dan Persentil Latensi

Ubah target ketersediaan menjadi waktu mati yang diizinkan, hitung kredit SLA dari gangguan nyata seperti Cloudflare 18 November 2025, lalu bangkitkan 1.000 permintaan API dan lihat mengapa p95 dan p99 lebih jujur daripada rata-rata.

Target dan gangguan bulan ini

Rumus

jatah mati = (1 − SLA) × menit sebulan ketersediaan = 1 − gangguan ÷ menit sebulan kredit (contoh tabel): < SLA → 10%, < 99% → 25%, < 95% → 100%

Bawaan 346 menit = gangguan Cloudflare 18 November 2025 (11.20–17.06 UTC). Tabel kredit adalah contoh umum; setiap penyedia punya tabel sendiri.

1.000 permintaan API stok TBS

Ingat

  • p95: 95% permintaan lebih cepat dari nilai ini
  • Rata-rata bisa terlihat baik padahal sebagian pengguna menunggu lama
  • Pengguna yang aktif memanggil puluhan API per sesi hampir pasti mengalami p99
