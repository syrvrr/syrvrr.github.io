Dosen · Peneliti · Praktisi TI

Ir. Andi Prayogi, S.Kom., M.Kom.

Dosen Tetap Prodi Sistem dan Teknologi Informasi dan Kepala IT, Institut Teknologi Sawit Indonesia (ITSI). Jabatan fungsional Asisten Ahli. Medan, Sumatera Utara.

Saya mengajar pemrograman, ERP, jaringan saraf tiruan, dan tata kelola TI di Prodi Sistem dan Teknologi Informasi ITSI, sekaligus mengelola infrastruktur TI kampus sebagai Kepala IT. Penelitian saya membawa machine learning, visi komputer, dan IoT ke kebun dan pabrik kelapa sawit: deteksi Ganoderma dengan YOLO, kematangan TBS dari citra, sistem pengawasan tangki berbasis IoT dan GPS dan Pemantauan Pekerja kebun dengan ciptakan Helm Pintar berbasis IoT.

Peta keahlian

Riset saya berada di irisan machine learning dan Internet of Things, keduanya bagian dari kecerdasan buatan. Data science, cloud computing, dan jaringan menopang irisan itu, dan keenam bidang ini saya ajarkan lewat mata kuliah di Prodi STI.

  • Machine Learning

    Deteksi dini Ganoderma dengan YOLOv9 sampai YOLOv11, kematangan TBS dari citra, dan KNN untuk pengenalan wajah (tesis). Kuliah: Jaringan Saraf Tiruan.

  • Kecerdasan Buatan

    Backpropagation untuk penentuan jurusan (skripsi), ANFIS untuk pengenalan tajwid, dan buku Memahami Machine Learning melalui Jaringan Saraf Tiruan. Kuliah: Algoritma dan Struktur Data.

  • Internet of Things

    Helm pintar keselamatan kerja kebun, pengawasan tangki CPO dengan GPS, CCTV pendeteksi wajah, dan pengering kopi fuzzy berbasis Arduino. Kuliah: Mikroprosesor, Sistem Digital, Arsitektur Komputer.

  • Data Science

    Python, NumPy, dan Pandas untuk mengolah data produksi, lalu pembersihan data sebelum migrasi ERP. Kuliah: Pemrograman I, ERP I, ERP II.

  • Cloud Computing

    Mengelola server situs ITSI, situs jurnal, dan layanan shortlink kampus. Kuliah: Cloud Computing, Pemrograman II, Pemrograman Berbasis Web.

  • Networking

    Jaringan kampus ITSI, WiFi enterprise untuk klien sejak 2018, dan load balancing MikroTik dengan algoritma Dijkstra. Kuliah: Tata Kelola Infrastruktur STI.
